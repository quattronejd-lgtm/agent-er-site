Why is my custom GPT not using its knowledge files?

Short answer: A custom GPT does not read all of its knowledge files on every reply. It searches them for passages that look relevant, so if your files are long, messy, or never mentioned in the instructions, the GPT often answers from its general training instead. The fix is to name each file in your instructions, tell the GPT exactly when to use it, and tell it to say so when the answer is not in the files.

Why this happens

When you upload files to a custom GPT, it does not memorize them. Each time someone asks a question, it pulls a few matching pieces from the files into the conversation. If nothing matches well, it falls back on what it already knows, which can sound confident and still be wrong.

Large PDFs with tables, scanned pages, or mixed topics are harder to search. Short, clearly titled files are much easier for the GPT to find the right piece in.

People also report that a GPT will sometimes say it used a knowledge file when it did not. That is why you want it to quote or name the file it used.

How to fix it, step by step

  1. Split big documents into smaller files, one topic per file, with clear names like pricing.txt or return-policy.txt.
  2. Where you can, save files as plain text or markdown instead of scanned PDFs.
  3. In the Instructions box, list each file by name and say when to use it. For example, "For any pricing question, search pricing.txt."
  4. Add a fallback rule: "If the answer is not in the files, say you do not know and suggest contacting us."
  5. Ask the GPT to name the file it used at the end of each factual answer, at least while you are testing.
  6. Test with real questions in a fresh chat and check each answer against your actual files.

Common questions

Does a custom GPT read every file every time?

No. It searches the files for relevant passages based on the question. That is why clear file names and instructions that point to specific files make such a big difference.

Why does my GPT say it used my file when it did not?

The GPT can produce a confident answer that sounds like it came from your files. Asking it to name or quote the file it used makes it much easier to catch when it is guessing.

What file type works best for knowledge files?

Plain, well organized text is the easiest for the GPT to search. Many builders report better results with text or markdown files than with long scanned PDFs.

Can I stop my GPT from making things up?

You cannot remove the risk completely, but you can reduce it a lot by telling the GPT to answer only from its files and to say when it does not know.
