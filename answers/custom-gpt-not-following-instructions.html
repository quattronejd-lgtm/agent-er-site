Why is my custom GPT not following its instructions?

Short answer: A custom GPT usually stops following its instructions for one of three reasons: the instructions are long or contradict each other, the important rules were put in a knowledge file instead of the Instructions box, or a model update changed how the GPT reads them. The fix is to move every must-follow rule into the Instructions box, cut it down to a short list of clear rules, and test it in a fresh chat.

Why this happens

The Instructions box is the only place a custom GPT reads on every single reply. Knowledge files are searched only when a question seems to need them, so a rule hidden in a file is easy for the GPT to miss.

Instructions also tend to grow over time. Each time something goes wrong, people add another line. After a while, two lines quietly disagree, and the GPT splits the difference instead of following either one.

Finally, OpenAI updates the models behind custom GPTs. When that happens, a GPT that worked well can start acting differently even though you did not change anything.

How to fix it, step by step

  1. Copy your current instructions into a separate document so you have a safe backup before you change anything.
  2. Read every line and delete any rule that repeats or contradicts another rule.
  3. Rewrite vague rules so they are pass or fail. For example, change "be concise" to "keep every answer under 150 words."
  4. Move any rule the GPT must always follow out of your knowledge files and into the Instructions box.
  5. Start the instructions by telling the GPT directly who it is and what its job is, such as "You are a booking assistant for a hair salon."
  6. Save, open a brand new chat with the GPT, and test it with three or four real questions your customers or clients ask.
  7. If it still drifts, try pasting the same instructions into a newly created GPT. Some builders report this clears up odd behavior after a model update.

Common questions

Why did my custom GPT suddenly get worse?

The most common cause is a change to the model behind it. When OpenAI updates the model, the same instructions can be read differently. Shortening and clarifying your instructions, then testing in a fresh chat, usually brings it back in line.

Is there a limit on how long custom GPT instructions can be?

Yes. The Instructions box has a character limit, and long instructions are also harder for the GPT to follow consistently. Keeping your rules short and specific works better than adding more text.

Should I put my rules in a knowledge file to save space?

No. Knowledge files are searched only when a question seems related, so rules stored there may not be read. Put rules in the Instructions box and use knowledge files for facts like prices, policies, and FAQs.

Will typing my instructions in ALL CAPS help?

It rarely fixes the real problem. Clear, specific rules that do not contradict each other work better than shouting the same vague rule louder.
